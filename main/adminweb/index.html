Yield is the share of that source's candidates still alive; it is the number that decides whether a source earns its place. The collector fetches the highest-priority sources first, so a source at the top is one that recently delivered working proxies. "Retry now" clears a source's failure cooldown so the next cycle fetches it in full.

One sample per minute, 24 hours kept. The queue sizes show how big the pool is; the rates show whether it is getting better or worse — a queue that stays flat while its dial-failure rate climbs is dying.

Edits are written to atomically, with the previous contents kept as .bak. The collector re-reads the file at the start of every cycle, so a change takes effect then; there is no restart. The list is never allowed to become empty.
